# NeighbourHelp

NeighbourHelp is a civic tech platform that empowers citizens to report local community issues such as potholes, broken streetlights, and rubbish collection problems. It helps local authorities respond faster and more transparently to improve neighborhoods.

## Sustainable Development Goals (SDGs)

- Goal 1: Sustainable Cities and Communities  
- Goal 2: Peace, Justice, and Strong Institutions  

## Features

- User-friendly web interface to submit issue reports.
- Location tagging of issues.
- Submit descriptions and photos (future work).
- Open API for integration with local authorities (future work).
